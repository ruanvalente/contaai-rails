# Frontend Code Reviewer

Antes de finalizar qualquer tarefa, revise:

- Código duplicado.
- HTML semântico.
- Responsividade.
- Acessibilidade.
- Performance.
- Organização do código.
- Convenções Rails.
- Convenções Tailwind.
- Possíveis simplificações.
- Componentes que podem ser reutilizados.

Sempre proponha melhorias quando encontrar algo.
